TAPVANTA WEBSITE

Files:
- index.html: website content
- style.css: design and responsive layout
- script.js: sample products, prices and Instagram order buttons

HOW TO USE:
1. Upload all four files to the same folder in your GitHub repository.
2. Keep the filenames unchanged.
3. Enable GitHub Pages from repository Settings > Pages > Deploy from a branch > main > /(root).
4. Edit product names and sample prices in script.js.
5. Instagram contact: @tap_vanta
   Email: tapvanta15@gmail.com

PAYMENT:
This starter website sends orders to Instagram DM. Confirm UPI details/QR manually with the customer after receiving the order. Cash on Delivery can also be arranged and confirmed in DM. No payment gateway is connected.

This is a static starter website; it does not store orders or process payments automatically.
